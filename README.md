# YouTube字幕抽出App

YouTubeのURLを入力するとその動画の字幕を抽出するWebアプリ。

## 仕様
- ログイン不要
- YouTube動画の字幕を簡単に抽出
- 抽出した字幕をテキストファイルとしてダウンロード可能
- 日本語や英語など多言語対応

## 画面構成
### Top画面
- **YouTubeの動画URLの入力欄**: ユーザーが字幕を抽出したいYouTube動画のURLを入力します。
- **字幕を表示**: 抽出された字幕が画面上に表示されます。
- **テキストでダウンロード**: 表示された字幕をテキストファイルとしてダウンロードするボタンを提供します。
- **言語選択可能**: 字幕の言語を選択するドロップダウンメニューを提供します。

## 技術スタック
- **Django**: Webアプリケーションのバックエンドフレームワークとして使用。

## 使用方法
1. アプリを開きます。
2. YouTube動画のURLを入力欄に貼り付けます。
3. 言語を選択します（デフォルトは日本語）。
4. 「字幕を抽出」ボタンをクリックします。
5. 抽出された字幕が画面に表示されます。
6. 必要に応じて「テキストでダウンロード」ボタンをクリックして字幕を保存します。
